## 逻辑框架（2026-10-15 反馈轮重构，用户拍板「导览页+章化」+主张句）

用户反馈：单页 ok 但整体逻辑框架没搭建。重构 = 主张先行 + 四章骨架可见 + 章问题链，**页序不动**（为什么→是什么→凭什么信→怎么用值多少 本身是标准汇报链）：

- **主线主张**（导览页大字）：AI 承担数据资产的设计开发，人守住判断权——交付提速 3~5×（内部口径），质量有机制底座。结束页三句话与它首尾呼应。
- **导览页**（封面后新增，16 页）：主张句 + 体系一页图（输入→流水线[⏸两闸口]→交付，三层防线带，底座带）+ 四章导航块（每章=章号+章问题+页列表）+ 抽页路线（赶时间/技术评审/想上手）。
- **页码章化**：`章-序 · 页名`（1-1 背景 / 2-1 形态 … 4-5 进展；导览=00）。
- **章首页标题升级为章问题**：为什么要做（背景）/ 做成了什么（形态）/ 凭什么可信（总纲）/ 怎么用、值多少（使用方式）。
- 四章：1 为什么要做[背景] → 2 做成了什么[形态/流转/编排] → 3 凭什么可信[总纲/校验/制品开发/人的位置] → 4 怎么用、值多少[使用方式/场景/实效边界/成果/进展]。
