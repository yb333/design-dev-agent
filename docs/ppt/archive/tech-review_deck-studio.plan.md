- 听众：技术评审/成果展示场合（技术项汇报），懂技术、不熟本项目细节

- 目标：听众离场记住——①多 agent 编排+确定性校验的架构 ②失败的分流设计 ③已落地到什么程度（数字+内网实测）

- 品牌/交付：蓝色三层默认主题；单 HTML 交付（deck-studio）
