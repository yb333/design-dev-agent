# 13 · 存量首优用户操作指南（用户视角，说人话）

> 读者：**发起优化的你**。存量资产（不是我们新建流程跑出来的）第一次做优化，从准备材料到拿到交付物，全程你会遇到什么、要回答什么，一页说清。流程内部机制不用你懂——那些在 00-12 章。

---

## 一、你要准备什么（四样）

| # | 材料 | 怎么准备 | 注意 |
|---|------|---------|------|
| 1 | **RS**（需求文档 md） | 按团队模板写；新字段的业务口径、要不要回刷、有没有 DQ 需求写清楚 | 表格加的"变更记录"列照常填；变更的**事实清单以 mapping 为准**，RS 是口径材料 |
| 2 | **mapping**（xlsx） | 实体级/属性级两页签填**当前最全最新的内容**（新字段行直接写进去）；**「变更记录」页签**记本次变更（八列：序号/时间/页签/key/列/类型/前/后——格式见 `docs/specs/mapping-format.md`） | 新增整行字段 → 变更列写"**资产字段**"；改名 = 先删后加两行；历史批次行留着不用删 |
| 3 | **原始制品**（这个资产在平台上的导出件） | 术加制品包 excel（**必有**）；LTS 调度 excel（资产是增量的才要）；DQ excel（有就给，没有发起时说一句"无 DQ"）；DDL 的 .sql 文件（有就给，没有也行——流程会查库补） | **文件名随意、怎么给都行**（发起时指认一下哪个是哪个） |
| 4 | **发起参数** | 见下节模板，照抄改路径 | 资产是第一次做优化才需要第 3 样；**做过一次之后，下次只要 RS + mapping 两样** |

## 二、怎么发起（参数模板，照抄改路径）

```
Task(
  subagent_type="dws-engineer",
  prompt="""模式: 优化
mapping: /abs/path/客户资产_台账.xlsx
rs: /abs/path/RS_客户资产.md
artifacts: {"execution_tasks": "/abs/path/制品A.xlsx", "lts": "/abs/path/调度.xlsx",
            "dq": {"status": "declared_absent"}, "ddl": ["/abs/path/ddl/"]}"""
)
```

- `artifacts` 里每个文件是哪个就填哪个路径——**类型靠你指认，文件名本身无要求**；
- 资产没有 DQ → `"dq": {"status": "declared_absent"}`（声明一次入档，以后不再问）；有 → `{"status": "provided", "path": "/abs/path/dq.xlsx"}`；
- 没有 DDL → 整个 `ddl` 键不填；
- **首次优化完成后档案建立**——下次优化把 `artifacts` 整段去掉，只剩 mapping + rs。

## 三、过程中你会被问什么（一共三次，都是选择题）

| 什么时候 | 问什么 | 怎么答 |
|---------|--------|--------|
| 输入预检 | 新字段源/目标**类型不匹配**（如源是数字、目标是文本） | 三选一：转换（我加安全处理）/ 不加（换口径）/ 返源端（改 mapping） |
| **闸口①'**（设计确认） | ① 新字段挂哪条规则、中间表加不加列——**落位表**给你确认 ② 增量资产才问：历史数据要不要回刷 ③ 设计师发现的存量问题要不要顺手修 | 看落位表对不对；回刷按业务需要；顺手修=本次范围扩大，自己权衡 |
| **闸口②'**（交付确认） | ① 新列跑出来的结果合不合理（空值率/样例一屏） ② 交付物清单确认 | 数据有问题说问题（流程会帮你定位根因归属）；没问题就确认收尾 |

不问答就停着——**流程不会替你做语义决定**。每次都是具体的问题+选项，不会甩给你一面墙的 diff。

## 四、结束你拿到什么（都在 `build/` 目录）

| 交付物 | 你拿去做什么 |
|--------|------------|
| `ddl/alter_table_*.sql` | **自己去库里执行**（加列变更单——流程不碰生产库） |
| `export/patched/制品.xlsx` | **自己导入术加平台**（更新后的完整制品包，SQL 和字段登记都改好了，不用手工拼 diff） |
| `etl/R000X.sql` | 参照/审阅（正式生效走平台导入，不是直接跑脚本） |
| `ut_report_opt.md` / `gate_summary_opt.md` | 审阅材料（测试结果、设计摘要） |
| `patch_notes.md` | 制品改了哪几处的清单 |

**推生产全部是你按按钮**——流程只生成交付物，不执行。

## 五、两个常见问题

**问：我怎么知道这个资产是不是"第一次"？** 答：不用知道——发起时给不给 `artifacts` 就是开关；给错了（资产其实有档）流程会拦下问你。

**问：优化做完，下次呢？** 答：准备两样：新的 RS + 在上次 mapping 基础上改（变更记录页签加一批新行）。原始制品、逆向、指认——都不再需要，档案已经接管。
