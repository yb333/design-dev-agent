# Mapping 文件格式说明

> 本文档说明 **mapping.xlsx 的 2 个 sheet** 的列定义与填写规范。
> 输入整体结构（mapping + RS 如何组合、rs_input.json 如何生成）见 [rs-input-format.md](./rs-input-format.md)。
> **标准模板**：`docs/templates/mapping模板.xlsx`——与实际业务模板对齐，如有变更同步更新。

---

## 文件结构总览

mapping.xlsx 只包含 **2 个 sheet**：

| Sheet | 名称 | 必须 | 说明 |
|------|------|------|------|
| 1 | 实体级mapping | ✅ | 源表与目标表的关联关系（表级） |
| 2 | 属性级mapping | ✅ | 字段级别的映射规则（字段级） |

> 调度/执行平台/设计配置等信息**不在 mapping**，见 RS 文档。

---

## Sheet 1: 实体级 mapping

定义源表与目标表之间的关联关系。

### 列定义

| 列名 | 必须 | 说明 | 示例 |
|------|------|------|------|
| 序号 | ❌ | 行号 | `1` |
| 分组 | ❌ | 场景分组（默认 default） | `default` |
| 源表schema* | ✅ | 源表所属 schema | `fin_dwl_cnb` |
| 源表中文名 | ❌ | 源表中文名 | `合同pu指标表` |
| 源表物理表名* | ✅ | 源表物理表名 | `dwl_con_pu_mtr_f` |
| 源表别名* | ✅ | 区分同一源表的不同关联实例 | `t`、`f`、`inv_mtr` |
| 目标表逻辑schema* | ✅ | 目标表所属 schema | `fin_dwl_cnb` |
| 目标表中文名 | ❌ | 目标表中文名 | `合同pu分析表` |
| 目标表物理名称* | ✅ | 目标表物理表名 | `dwl_con_pu_any_f` |
| 取数规则 | ❌ | 特殊取数方式说明 | |
| 关联&限定条件 | ❌ | 源表与主表的关联条件，主表填说明 | `left join on t.contract_key = f.contract_key` |
| 备注 | ❌ | 补充说明 | `需排除非洲发票` |
| 数据库类型 | ❌ | 数据库类型（预留） | |

### 源表别名说明

当同一张源表被关联多次（不同关联实例），用别名区分。别名在属性级 mapping 中用于标识字段来源。

---

## Sheet 2: 属性级 mapping

定义字段级别的映射规则：每个目标字段从哪个源字段来、怎么转换。

### 列定义

| 列名 | 必须 | 说明 | 示例 |
|------|------|------|------|
| 序号 | ❌ | 行号 | `1` |
| 分组 | ❌ | 场景分组 | `default` |
| 源Schema | ❌ | 源表schema（可从实体级推导） | `fin_dwl_cnb` |
| 源表物理表名 | ❌ | 源表名（可从实体级推导） | `dwl_con_pu_mtr_f` |
| 源表物理别名 | ✅ | 对应实体级的源表别名 | `t` |
| 源表字段中文名 | ❌ | 源字段中文注释 | `合同号` |
| 源表字段名 | ✅ | 源表字段名 | `contract_no` |
| 源表字段类型 | ❌ | 源字段数据类型 | `nvarchar(500)` |
| 映射规则* | ✅ | 转换类型分类（**具体分类值待与业务方对齐**） | `直取`、`行转列`、`聚合`（暂定） |
| 映射表达式 | ❌ | **自然语言描述**加工逻辑，**不含业务术语** | `rpt_code='fbt_0001'对应设备订货金额，按合同+pu汇总` |
| 目标字段名* | ✅ | 目标表字段名 | `contract_no` |
| 目标字段中文名 | ❌ | 目标字段注释 | `合同号` |
| 目标字段类型 | ✅ | 目标字段数据类型 | `nvarchar(500)` |
| 备注 | ❌ | 补充说明 | `主键` |
| 数据标准 | ❌ | 数据标准引用（预留） | |

### ⚠️ 映射表达式的填写要求

- **必须用自然语言**，不要写 SQL 表达式（如 `SUM(CASE WHEN...)`）
- **不含业务术语**（预检会校验）—— BA 能看懂的描述，不要用内部黑话
- 描述"算什么、什么口径"，不描述"SQL怎么拼"
- 复杂逻辑（行转列/聚合/多步）必须写说明，简单直取可填"-"
